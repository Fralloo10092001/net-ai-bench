A new inet filter table is created with an input chain set to policy drop. An early rule accepts all traffic on eth0 to preserve existing management connectivity. Loopback, established/related traffic, ICMP, TCP/2222, and UDP/5555 are allowed. A final logging rule drops remaining inbound traffic with prefix FW_INPUT_DROP. The existing ip nat table is untouched, addressing is unchanged, and no firewall state is flushed.
