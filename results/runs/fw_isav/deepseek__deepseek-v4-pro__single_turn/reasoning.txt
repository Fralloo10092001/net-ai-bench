On the firewall (fw), we enable strict reverse-path filtering on the WAN-facing interface eth1 to drop packets with a source address not reachable via that interface. Additionally, we add iptables rules to explicitly drop any traffic entering eth1 with a source IP in the protected LAN prefix 10.10.20.0/24, covering both locally destined packets (INPUT) and forwarded packets (FORWARD). This prevents amplification/reflection attacks using spoofed LAN addresses from the WAN while preserving normal forwarding from WAN to LAN.
