The firewall 'fw' has an nftables 'inet filter' table with a 'forward' chain that has a default policy of 'drop'. Existing rules allow TCP port 2222 traffic from client (eth1) to server (eth2) and its return traffic. To allow SSH (TCP port 22) from client to server, two new rules are required: one to permit new and established connections from client to server on port 22, and another to permit established return traffic from server to client on port 22. These rules are added to the 'forward' chain on 'fw' using 'nft add rule' to ensure they are additive and do not disrupt existing firewall state or other services.
